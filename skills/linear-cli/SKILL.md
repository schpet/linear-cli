Run `linear skill show` before your first `linear` command and follow the guide
it prints. Run it on its own and read all of it. The guide comes from the
installed linear CLI, so it describes the commands that version has.

If the command fails, `linear` is missing from PATH or predates the guide. Tell
the user, and if `linear --help` works, use it and `linear COMMAND --help`.
