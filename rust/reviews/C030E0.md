## Observations for the C030 matrix

- **Parser.** Missing `--project` (with or without `--json`), `--project` with no value, a separate empty `--project ""`, a trailing `--project=`, a repeated `--project`, a repeated `-j`, an extra positional and an unknown flag all fail as Cliffy usage errors (exit 2, usage on stdout, error on stderr, no request). **`--project=` and `--project` consume the next argv as the value.** `--project= --json`, `--project --json` and `--project -j` therefore look up the literal `--json`/`-j` by name and then by slug in text mode, and fail with the resolver not-found message. `--project=<uuid>` works, and `--workspace` resolves before or after the leaf flags. Clap will need scoped parser goldens for these value-consumption cases.
- **Error prefix.** Every handled action error has exactly one `✗ Failed to fetch milestones:` prefix. This covers the missing API key (after UUID pass-through and before name lookup), the env-key/`--workspace` conflict, an unknown `--workspace`, all URL errors, ambiguity, not-found, GraphQL, HTTP, null-root, cursor and V8 TypeError failures. **A malformed credentials file is not prefixed.** It is an uncaught top-level module-load error with a Deno stack trace, it exits 1, and it takes precedence over parser errors. Rust needs a reviewed golden for that startup path rather than copying the prefix.
- **Resolver order.** URL shape, kind and workspace checks run before credentials. URL workspace mismatch also wins over the LINEAR_API_KEY/`--workspace` conflict, and its suggestion follows the key source: env key, config `api_key`, or neither. The credentials-file default workspace also drives URL validation, and the workspace match ignores case. A project URL sends only the slug lookup. UUIDs in either case pass through verbatim with zero lookups. A name lookup is followed by a slug lookup on a miss, and the first slug match wins. Two name matches are ambiguous. Whitespace-only input is looked up verbatim. A raw `projects: null` name response counts as a miss.
- **Not-found variants.** Resolver not-found carries the `Pass a project UUID, slug ID …` suggestion. A null root `project` has no suggestion and echoes the raw flag value (uppercase UUID, URL or name). A later-page null root discards earlier pages. A direct UUID GraphQL entity-not-found prints `userPresentableMessage` and stays distinct from the null-root path. HTTP failures print graphql-request's `GraphQL Error (Code: N): {response…,request…}` dump, which includes the full query and variables. A GraphQL error on page 2 discards page 1.
- **Pagination.** `first: 100` is sent on every page and `after` is omitted on the first. Null or empty `endCursor` with `hasNextPage` fails with `Linear reported more milestones but returned no pagination cursor` / `Retry the command.` and no output. A final empty cursor is kept as `""` in JSON, and the final `pageInfo` of two- and three-page runs is emitted as received. **Finite repeated cursor:** Deno makes all three requests, reusing `after: "same"`, and prints the duplicate node in both JSON and text. The planned Rust stop after two requests needs a scoped v3 golden. A truly cyclic cursor stays out of this corpus.
- **JSON.** The output is the `{nodes,pageInfo}` connection with two-space indent and a final LF. Wire key order and extra wire fields (node `description`/`__typename`, nested `slugId`, `pageInfo.startCursor`) pass through. A missing `sortOrder` key stays absent and a null stays null. A lone numeric `targetDate` prints as a number and an object `targetDate` prints as an object. Number text: `-0`→`0`, `1e21`→`1e+21`, `0.1`, `5e-324`, `1.7976931348623157e+308`, `123456789.125`, `1.0`→`1`, and **`1e400`→`null`**.
- **Sort.** Dates are compared with `localeCompare`, empty-string and null dates sort last, and ties fall back to name `localeCompare`. `sortOrder` has no effect. The observed order within one date is `🚀 Launch`, `10 items`, `9 items`, `apple`, `Apple`, `banana`, `éclair`, `Émile`, `Eve`, `Tie`(wire 1st), `Tie`(wire 2nd), `Zulu`. So symbols sort first, digits compare non-numerically, lowercase precedes uppercase on case ties, accents are secondary, and V8's sort is stable. Null/empty-date rows print `No date`. Two numeric dates throw `a.targetDate.localeCompare is not a function`. `projectMilestones: null` and `nodes: null` throw the observed V8 TypeErrors. Missing outer project `id`/`name`, a missing nested project `id` and missing or null `sortOrder` do not affect text.
- **Text.** Piped width is 120. The project column is `min(30, max(7, widest name))`, and the name column is `min(widest name, 120 − 1 − fixed)`. Truncation compares UTF-16 `.length` while padding uses `unicodeWidth`. A long ASCII name therefore becomes 34 units plus `...`, and a 37-character CJK name (74 columns) is not truncated and overflows. Slicing inside a surrogate pair emits **U+FFFD** before `...`. A project name over 30 is sliced to 27 plus `...`, and a CJK project name is padded by display width. A one-character name does not widen the column to the `NAME` header, so rows are misaligned. The empty result prints `No milestones found for this project.`. With stdout closed at start, both text and JSON exit 0 with empty stderr. In pipe mode, unset and empty `NO_COLOR` give bytes identical to `NO_COLOR=1` for the table; an unset-`NO_COLOR` handled error also matches the no-color baseline. The empty-`NO_COLOR` handled-error branch is not captured.

## Known coverage limits

- The strict runner has no PTY format, and no direct PTY probe was run. Spinner start/stop timing, header underline and handled-error colour, the empty-`NO_COLOR` asymmetry, 40-column and zero-width terminals, and `consoleSize()` failure versus Rust `stdout_columns() == 0` stay C030 QA work. No terminal bytes are claimed as parity.
- Not captured: keyring-format credentials, an unreadable credentials file, empty or duplicate `--workspace`, 401/429 responses, delays and timeouts, non-JSON 200 bodies, a node missing `name` or its nested `project`, a text-mode object `targetDate`, and a JSON response with missing outer project fields.
- ICU root ordering is established only for the captured names and dates; the Rust collator needs its own tests beyond these examples. Nothing depends on the clock.
- Strict typed Rust decoding will reject several shapes that Deno accepts: extra fields, missing outer or nested fields, null or missing `sortOrder`, wrong-type dates and overflow. Each needs its own reviewed v3 golden, as do the parser value-consumption cases, the startup credential error and the HTTP error dump.
- An independent Sol read-only audit found no material source-to-fixture defect. A fresh Claude evidence review returned SHIP after an endpoint guard and the two claim corrections above. No live Linear call or credential was used.
