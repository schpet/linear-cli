# R02B3 — typed config startup

This is a foundation slice. The Rust binary now captures relevant process inputs, discovers and parses selected dotenv/TOML files, validates the typed option snapshot, and reports startup warnings or errors before route parsing. Help, version and Markdown need no credential. The active custom command parser and network/auth actions are unchanged. `R02C2` owns credential-file/keyring startup, `R02B4` owns the async transport adapter, and command leaves remain unimplemented unless separately recorded.
