## Change and classification

The tracked `f01d3-routes.json` is a portable exact 20-parent allowlist in manifest order, without a program path. The stdlib materializer checks the template against the pinned manifest, validates an absolute executable realpath outside the runner's forbidden bind prefixes, and writes an ignored full runner-schema descriptor under `rust/target/` atomically. `--check` detects stale descriptor text. The generated descriptor is submitted to the unchanged runner schema. A descriptor with no leaf route cannot launch the Rust binary for a leaf case; the runner self-check also tests `not-implemented-from-descriptor` by requiring no candidate observation (`result.candidate == null`).

The three parser corrections are bounded: generated `TypeHandler::Variable` checks for `=` inside value consumption before standalone validation; missing values report the canonical long option name; short equals flags preserve their value on the final short option. No enum type validation or action implementation is claimed. `parser-invalid-variable` is the frozen exact-byte anchor. The short-alias/equals and Variable ordering matrix is source-derived from frozen Cliffy `flags.ts` (cached source SHA-256 `d5da21d5f49ceb5252e5aa7090211639585e8f6df1f359d61d121031abcf0eb1`) and frozen `src/commands/api.ts` (SHA-256 `b9ea81207301f386b36fab50abe0f3b35a6ab0104a7b9e742a1de5f0b505da60`), not a new oracle capture.
