## Scope and decisions

- Generated route metadata is typed for arguments, option defaults, local enum/variable types, route kinds and parent actions. The generator validates the inventory shape and alias resolution rather than silently dropping unsupported fields. It preserves all 110 routes, 36 aliases, option order and examples. The source exporter represents most absent option defaults as null; the renderer emits hints only for the six non-null values and enum values known from the frozen source and cases.
- Added a bounded renderer for Cliffy help: Deno color nesting, command/option/description/example sections, pinned table widths, wrapping and ANSI continuation. `unicode-width = 0.2.2` is the sole runtime dependency added for terminal cell width; its version is pinned exactly in Cargo.toml and Cargo.lock.
- Public `run` now handles route-terminal `-h`/`--help`, non-root parent bare help, root long version, and retains root/document bare hints and root short version. Leaf actions remain visibly unimplemented. F01D2 owns global-leading flags, equals forms, bundles, missing values and usage errors. Exact help fixtures establish presentation only, not implementation of those routes.
- `NO_COLOR` is nonempty-only. Help/table styles disappear for `NO_COLOR=1`; Deno-inspect default/enum literals retain their ANSI coloring, as witnessed by the accepted C2 mine case.
