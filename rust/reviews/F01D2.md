## Boundary and decisions

The new typed parser carries remaining argv, ordered standalone actions, a standalone marker across parse passes, parsed option values, literal `--` tokens, and the selected generated route. It performs Cliffy's first-token child lookup, global-option preparse and child retry, then a route-local full pass. Inherited unshadowed globals precede route help/version and locals. It handles aliases, long equals values, short bundles used by the accepted cases, required nonempty values that consume dash-leading tokens, route-specific usage diagnostics, and closest visible-command or option suggestions. The app writes the failing route's short help to stdout before the exact usage diagnostic on stderr; domain validation remains exit 1. Short `-V` is selected ahead of queued async actions when the deepest raw argv lacks exact `--version`.

Leaf actions still return a visible `Unimplemented` error. The 22 cases here establish parser and terminal error behavior, not implementation of leaf actions. No Deno source, GraphQL, parity runner/cases, Docker, live Linear, or push is involved.

## Independent review correction

Claude's first D2 diff review gave a no-ship verdict because the standalone marker was local to a single option-parse pass. Frozen Cliffy persists `ctx.standalone` across the root/child recursion and validates the current pass's explicit options against that marker. The parser now retains the marker in `ParseContext`, while `seen` remains per pass. Source-derived public-run tests assert exact route help and diagnostic bytes for `issue view -h --json`, `--help issue view --json`, both reverse/order controls, and the analogous `issue mine --sort` cases. They also preserve the successful controls `--workspace ws issue --help` and `-h -V`. The same review found two bounded value errors: empty required next tokens now report a missing value (including workspace and required variadic `--bulk`), empty optional next tokens are left unconsumed, and inline values on zero-argument options now report Cliffy's exact `doesn't take a value` diagnostic. `--help=` without a nonempty inline value remains accepted. These source-derived cases are separate from the 22 frozen fixtures.

After those changes, generator freshness, Cargo fmt, one-job full Clippy with `-D warnings`, workspace tests and build all passed. Separate direct-binary QA matched all 22 frozen cases and six new controls exactly. No new dependency or manifest/corpus edit was needed.

Claude's narrow closeout verdict was ship. It reproduced the blocker fix and selected controls, and identified two further source-verified parser deviations outside the D2 frozen selection: missing-value errors reached through a short alias currently print that alias instead of the canonical long option, and short flags with an equals value are split as bundles before their value is parsed. These are tracked for F01D3 with exact Deno/Rust controls; D2 does not claim their parity.
