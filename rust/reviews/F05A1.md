`Output` writes all bytes and flushes the same stream before returning. Its typed source identifies stdout/stderr and write/flush, with the underlying `io::Error` still in the source chain. The library `finalize` function handles route results and final flushes; any write/flush failure wins as `IoProcess` and process status 1, including over usage or child exit codes. It attempts one stderr diagnostic for a stdout failure, never recurses when stderr fails. Bootstrap errors use the same single flushed stderr attempt and status 1. `main.rs` only acquires process streams/inputs, calls `run` and `finalize`, and maps the result to `ExitCode`. `BrokenPipe` remains a provisional IO failure; F05A3 will decide its exact policy from P04A2 evidence.

Its failing writers cover no-newline flush, partial write, stdout/stderr failures, final flush priority over success/usage/child code, a real usage render followed by a second-flush IO failure, bootstrap flush, persistent flush with exactly one output-failure diagnostic, and provisional BrokenPipe. ## Known boundary

A file descriptor 1 closed **before** process startup yields exit 0 and empty output for both the A1 Rust candidate and the frozen compiled Deno reference on offline root/help/version routes. This is an observed Linux compatibility case, not a deviation; A1 needs no `/proc` guard. A reader-less **open pipe** whose reader closes after spawn is distinct and belongs to P04A2/F05A3. This slice does not add a process adapter, fixture schema, command routes, or dependencies.
