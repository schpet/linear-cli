# C039P — plain prompt foundation for `initiative create`

C039P adds a reusable Rust text/plain-list prompt session for the later C039 action. It does not register a CLI route, call GraphQL or use the live Linear workspace. Terminal stdin uses individual keys and restores Unix termios; piped stdin uses a strict LF-delimited script whose unread bytes persist across the six prompts. The script contract is a planned v3 direct-only prompt behavior, not a claim that Cliffy's chunked piped-input behavior is byte-identical. C039A will bind its command-level prompt and effect results.
