# C031 — typed Rust `milestone view`

The Rust `milestone view`/`v` route now runs typed Cynic project resolution, milestone details and issue pagination. It supports direct UUIDs, project-scoped names, GraphQL-shaped JSON, source-compatible text previews, and `--all`; it rejects bare Linear milestone URLs with v3 guidance. The source Deno tree and frozen baseline are unchanged. No new dependency was added. The only uncommitted C031 action changes are the route, Cynic operations, public tests, 76 case promotions, 70 case-specific SHA-pinned goldens, the C031 guard, global corpus assertions, coverage manifest and this documentation.
