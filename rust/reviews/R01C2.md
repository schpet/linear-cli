# R01C2 — production clap parser cutover

Status: candidate on local `rust-port` base `d5e53d7b` (R02C2G), in isolated jj workspace `linear-cli-rust-r01c2`; coordinator `@`, `main` and remote are untouched. The frozen reference is Deno 2.6.0. The Rust package stays `3.0.0-alpha.1` with pinned `clap =4.6.7` and its existing `error-context` feature; `Cargo.toml` and `Cargo.lock` are unchanged. The file-backed C2 microplan received independent Claude SHIP before implementation.

## Production boundary

`app::run` writes and checks R02C2 startup results before parsing, then calls `clap_input::parse` and passes the complete owned `ParsedAction` to `dispatch`. Route selection still uses `action.route`, while positionals, literals, selected workspace, typed options and origins remain on the invocation for later leaf handlers. Help, version, usage, stdout/stderr split, flush/write failure priority and C085 Markdown dispatch use the existing renderer and output layer. The old parser remains compiled solely as legacy evidence pending R01D removal. Six direct old-parser contract tests are named `legacy_parser_*`; new production contracts exercise the binary, typed invocation, all 110 routes and 36 aliases.

The effective-spelling helper now returns inherited rows before local rows on every route, as the old renderer did. The renderer consumes that helper, so only `label list` changes spelling/order: inherited `--workspace <slug>` before `--team`, local Boolean `--workspace-only` after `--team`. The 110-route row-order contract and the frozen terminal cases guard all other route help. `c2-label-list-help` retains frozen expected bytes and binds `R01C2-LABEL-LIST-HELP` with stdout SHA `291a38241c8d2aec75b943a1de06c543f185330628f08888a78ed4a2b272993b`.
