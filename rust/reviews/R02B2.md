# R02B2 typed option snapshot

Status: Claude narrow closeout **SHIP**. Rebased without conflict from `9728645f` onto R01B3 `acbf9157` for coordinator integration. This slice is a pure, injected config library. It does not read process globals, wire startup, dispatch a command, load credentials, send a request, or change current binary output.

`config::ConfigOptions::from_inputs` accepts A2's selected global/project TOML tiers, B1's original process environment and applied dotenv assignments, and the injected absolute cwd. It parses all twelve frozen `OptionSchemas` keys in frozen key order; for each key, it parses process env, applied dotenv, project TOML, then global TOML before selecting the highest present valid value. An invalid shadowed value is fatal. Unknown TOML keys are inert. Empty strings remain present. Typed field accessors avoid caller downcasts. Only `issue_sort` and `pr_template` expose typed CLI override methods, matching the frozen call sites; CLI workspace remains separate from sourced `workspace`. `issue_sort` returns `Priority` without a source when absent.

Each selected value carries its source and selected file path. `pr_template` uses the exact ECMAScript trim character set and rejects empty text; config-sourced templates resolve to an absolute path relative to their config file, including a relative XDG/APPDATA config base resolved through injected cwd. CLI/env/dotenv paths stay relative. `attachment_dir` remains raw text for its later consumer. The endpoint is separate from the twelve schemas: absent or explicit empty value selects `https://api.linear.app/graphql`; a nonempty process or applied-dotenv value is parsed through `EndpointUrl`. Endpoint parse errors are reduced to a fixed category, without chaining parser details. `api_key` is checked only for string type here and wrapped in `ConfigSecret`; R02C owns header-byte and whitespace validation. `ConfigOptions`, `Resolved<T>`, `ConfigSecret`, endpoint wrappers and option errors do not format values.

## Compatibility and hand-off

These are **library decisions**, not current binary behavior. R02B3 must capture frozen Deno bytes and add case-specific versioned Rust goldens before startup activation:

| Input                                                                                    | Frozen Deno behavior                                                                             | Planned Rust v3 behavior                                          | Migration                                                        |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------- | ---------------------------------------------------------------- |
| Invalid shadowed known key, such as global `issue_sort = "bad"` with valid project value | The higher selected value wins; the bad lower value is not parsed                                | Startup fails with key and source/path, without echoing the value | Correct every present known-key value in all selected tiers.     |
| `LINEAR_DOWNLOAD_IMAGES=` or another present empty boolean/enum                          | `getOptionWithSource` returns no value after failed schema parsing                               | Startup reports invalid boolean/choice                            | Unset the variable or give a listed value.                       |
| Invalid `issue_sort` or `pr_template`                                                    | Deno's specialized resolver may echo the raw value; other generic options may silently disappear | Startup reports a fixed, value-redacted category                  | Correct the named key at the stated source/path.                 |
| Malformed nonempty `LINEAR_GRAPHQL_ENDPOINT`                                             | Failure can be deferred to a request                                                             | Startup rejects it, including offline routes                      | Set an HTTP(S) URL without credentials or fragment, or unset it. |

The frozen source has no CLI-fed `getOption` callers beyond `resolveIssueSort(--sort)` and `resolvePrTemplate(--template/--no-template)`. The closed typed override methods enforce that architectural boundary; R02B3 maps parser values into them and retains the existing usage-error channel for malformed registered CLI values. R02B3 also maps `ConfigOptionError` to user-facing handled error text and writes the public compatibility ledger. B1's Windows dotenv parser still filters process-shadowed keys case-sensitively; B2 ignores a differently-cased dotenv duplicate when a normalized process key exists, and R02B3/G02 should normalize applied dotenv names at its boundary. The later `issue view` consumer needs `TMPDIR`/`TMP`/`TEMP` in its own environment inputs. No live Linear verification applies to this library slice.
