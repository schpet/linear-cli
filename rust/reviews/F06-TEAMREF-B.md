# F06-TEAMREF-B: typed team reference lookup

This library slice resolves a prepared team reference to a typed `{ id, key, name }` value. `prepare_team_lookup` runs synchronously before credential selection or transport construction, so blank input, unsupported Linear URLs, wrong URL kinds, and workspace mismatches retain their error precedence. `find_team` sends one minimal `ResolveTeam` query and chooses an exact case-insensitive key, then the first UUID alias node, then a unique name. `resolve_team` fetches all team pages only after a miss and returns the frozen error with an ordered key suggestion. The public wrapper accepts an already-built transport; B adds no command dispatch, credential selection, renderer, or live Linear call.
