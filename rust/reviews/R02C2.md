The binary now loads typed config, then the credential file, then eager keyring metadata before clap parses help or version. A config failure stops before any credential read. A missing credential file becomes an empty store; any other file read failure, nonregular file, oversize input, invalid UTF-8/BOM/TOML or credential shape error fails startup with a fixed category and repair suggestion. The file reader opens once and bounds the read to 1 MiB + 1 byte. On Unix it requests nonblocking open so FIFO paths can be classified without waiting. Diagnostics contain no parser source text or secret value. Credential warnings follow config warnings, then invalid default, then configured metadata order.

On Linux, each metadata workspace invokes exactly `secret-tool lookup service linear-cli account <workspace>`, with null stdin and piped output. The direct child inherits the complete unmodified process environment, including private PATH in tests; selected dotenv values are not overlaid. A zero exit with nonempty stdout returns the key, a zero exit with empty stdout or exit 1 with JavaScript-trim-empty stderr is a miss, and other outcomes become fixed-category warnings. The adapter strips one leading UTF-8 BOM from stdout as Deno TextDecoder does. It caps stdout at 64 KiB, stderr at 16 KiB, and each lookup at 30 seconds; it kills/reaps the direct child on cap/deadline/read failure. A direct child whose descendant holds a pipe open gets a 500 ms post-exit grace, then a typed `PipeHeldOpen` failure; detached descendants are not killed. Startup uses at most eight concurrent lookup workers and a 60-second new-work deadline; an in-flight call can extend completion by at most its remaining 30-second bound. Unstarted lookups receive fixed `Other` warnings. These bounds differ intentionally from Deno's unbounded Promise.all. On other targets, inline/empty credentials work and metadata receives an explicit unsupported-platform warning until native adapters are qualified under G02.
