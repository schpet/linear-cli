Fractional and out-of-range values are rejected locally as invalid GraphQL Ints before a request. A null project names the original argument in its not-found error. Color is emitted only on a terminal, with Deno's exact health, gray body and reset codes. All failures get one `Failed to fetch project updates` context. No new dependency was added.
