# P03A: GraphQL case contract and matcher

This slice freezes the optional `graphql` case block. It is mutually exclusive with a non-null `fixtureServer`; both require the `fixturePort` substitution. `expectedRequests` counts every GraphQL and asset interaction across all groups exactly. P02 case JSON remains valid without a `graphql` key. The schema digest must match both `graphql/schema.graphql` and `rust/parity/baseline.json`.

Example case block (the surrounding P02 case fields remain required):

```json
{
  "graphql": {
    "path": "/graphql",
    "schemaSha256": "eef86b69c116d6adcb4f3659c29f9eb1407f84846f03cfda0b6096a80df3729a",
    "expectedRequests": 2,
    "initialRecords": { "User:u1": { "id": "u1", "name": "Ada" } },
    "expectedRecords": { "User:u1": { "id": "u1", "name": "Ada" } },
    "groups": [{
      "mode": "ordered",
      "steps": [
        {
          "kind": "graphql",
          "id": "viewer",
          "operation": {
            "document": "query Viewer { viewer { id name } }",
            "exactOrigins": [],
            "allowExtraTypename": false
          },
          "identity": {
            "authorization": "lin_api_fake",
            "userAgent": "schpet-linear-cli/2.6.0",
            "headers": {}
          },
          "response": {
            "kind": "data",
            "data": { "viewer": { "id": "u1", "name": "Ada" } }
          },
          "effects": []
        },
        {
          "kind": "asset",
          "id": "download",
          "method": "GET",
          "path": "/signed/file?token=fake",
          "requiredHeaders": {},
          "forbiddenHeaders": ["Authorization"],
          "body": { "utf8": "" },
          "response": {
            "status": 200,
            "headers": { "Content-Type": "application/octet-stream" },
            "body": { "base64": "AAE=" }
          }
        }
      ]
    }]
  }
}
```

Operation inputs accept optional `operationName` only to select one operation in a multi-operation document, optional raw `variables`, optional `exactOrigins` paths (for example `$.viewer.id` for an argument named `id`), and optional `allowExtraTypename`. The matcher ignores operation, fragment, and variable names. It compares selected schema fields, aliases, directives, mutation field order, effective argument and nested input values, and provenance. Omitted, explicit null, variable default, argument default, and input-field default are distinct. Literal and variable values match by default; `exactOrigins` asserts that source choice at named argument paths. Every supplied variable must be used; graphql-js rejects invalid nested input keys. Fixture records and response data use schema field names, not aliases; the server will apply aliases during execution.

`exactOrigins` paths start at `$`, append each response field and argument as `.name`, and append nested input fields as `.name` or list members as `[index]`. Directive arguments use `@directive[index].argument`, where the index is zero-based among directives on that selection: `$.user.name@include[0].if` is a field directive. Fragment directives append `#spread[index]` or `#inline[index]` before the directive, where the index is the selection's zero-based position in its parent set; for example `$.user#spread[0]@include[0].if`. Those explicit paths assert the literal-versus-variable choice at that exact scope. The loader rejects a path that does not exist in the expectation.

Other response forms:

```json
{ "kind": "graphqlErrors", "status": 200, "data": null, "errors": [{ "message": "Forbidden", "extensions": { "userPresentableMessage": "Access denied" }, "path": ["viewer"] }] }
{ "kind": "validationErrors", "status": 400, "errors": [{ "message": "Cannot query field" }] }
{ "kind": "transport", "status": 502, "headers": { "Content-Type": "text/plain" }, "body": { "utf8": "gateway error" } }
```

An ordered mutation can declare compare-and-swap state effects. `before` is either `{ "absent": true }` or `{ "value": ... }`; a delete requires a prior value. `partialEffects` is an optional explicit policy bit for later server slices.

```json
{ "kind": "put", "record": "Issue:i1", "before": { "absent": true }, "after": { "id": "i1" } }
{ "kind": "delete", "record": "Issue:i1", "before": { "value": { "id": "i1" } } }
```

Concurrent groups contain two to five named lanes with ordered steps. `timeoutMs` bounds the first-step overlap barrier; later steps advance in each lane's order. A resource cannot receive effects from more than one lane in a group.

```json
{
  "mode": "lanes",
  "timeoutMs": 5000,
  "lanes": [
    {
      "id": "first",
      "steps": [
        {
          "kind": "graphql",
          "id": "lookup-a",
          "operation": { "document": "{ viewer { id } }" },
          "identity": {
            "authorization": "lin_api_fake",
            "userAgent": "schpet-linear-cli/2.6.0",
            "headers": {}
          },
          "response": { "kind": "data", "data": { "viewer": { "id": "u1" } } },
          "effects": []
        }
      ]
    },
    {
      "id": "second",
      "steps": [
        {
          "kind": "graphql",
          "id": "lookup-b",
          "operation": { "document": "{ viewer { id } }" },
          "identity": {
            "authorization": "lin_api_fake",
            "userAgent": "schpet-linear-cli/2.6.0",
            "headers": {}
          },
          "response": { "kind": "data", "data": { "viewer": { "id": "u1" } } },
          "effects": []
        }
      ]
    }
  ]
}
```

Asset redirects name a declared route through `response.location`; paths are origin-relative and cannot traverse to another host. GET and PUT use the same byte representation. The loader validates case structure, IDs, counts, schema digest, expected operation validity (except deliberately expected validation-error responses), redirect closure, and conflicting concurrent effects. Actual HTTP matching, response execution, state effects, and asset serving belong to P03B/C.

## Review findings and dispositions

The fresh Claude review found five matcher gaps; public tests now demonstrate each fix: root query/mutation kind, singleton-list coercion, composed fragment and field directives, JSON scalar objects with an `origin` key, and introspection meta-fields. Coordinator repros added tests for aliased `__typename` under the opt-in and nested concrete type conditions. The matcher now keeps all applicable directives and type conditions instead of overwriting ancestors. Its provenance marker is private to normalized values, so a user JSON object is never mistaken for matcher metadata.

The closeout review found a literal/variable false negative when sibling aliases were sorted before provenance removal. Merge and sort keys now use the same provenance-free shape as final comparison; a public test exercises both directions. A schema test rejects User-Agent versions other than the frozen `2.6.0`, and matcher tests cover field and fragment directive `exactOrigins` paths.

The loader now rejects a fixture whose operation fails to match itself, including an impossible `exactOrigins` path. Until P03B implements GraphQL execution, `executeCase` raises a harness error before creating a sandbox for any GraphQL case. The User-Agent literal is pinned to the frozen `d4fe6fa7` reference's `2.6.0`, independent of a future checkout version bump. Rebase onto `2185e057` retained P02B's `expected.exit.signal` guard and `Deno.lstat` fixture check.

Deferred to P03B: compare absent `variables` with explicit `{}` at the HTTP envelope, assert response and state effects against actual execution, and improve mismatch messages with the first differing field path. The matcher conservatively treats a redundant interface condition within a concrete condition as distinct (`... on User { ... on Node { id } }` versus `... on User { id }`); P03B can normalize this once real captured documents require it. The loader currently re-reads and rebuilds the pinned SDL for each GraphQL case; cache it when broad case capture begins. GraphQL block strings containing raw malformed `{{` are rejected by the existing placeholder scanner; case authors should encode byte payloads as base64 when those literal bytes are needed.
