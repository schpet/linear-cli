This item binds the ten R02C2E0 frozen Deno startup cases to the Rust `3.0.0-alpha.1` candidate. It moves the unchanged Deno cases and eight synthetic config fixtures into the main corpus, adds ten SHA-pinned v3 goldens, and names the startup difference `R02C2G-CREDENTIAL-STARTUP`. It changes no Rust code, dependency, leaf route, host credential, or live Linear state.
