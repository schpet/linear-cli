The 25 new cases cover:

- **Team URLs and workspaces:** a team URL's uppercased key; root `--workspace beta` sending its credential to both requests with a same-workspace URL; a URL/workspace mismatch; an unknown workspace; and `LINEAR_API_KEY` combined with `--workspace`.
- **Errors before credentials:** a wrong-kind URL and a blank `--team`, both without an API key; an unsupported team subpage is rejected before client creation with a fake API key set.
- **Lookup failures that never fetch templates:** a `ResolveTeam` GraphQL error, and a miss in a workspace with no teams (the no-teams suggestion).
- **Template request failures:** HTTP 401 with a JSON `userPresentableMessage`; HTTP 500 with a plain body and graphql-request's full `ClientError` text; `userPresentableMessage` winning over `message`; partial data plus errors.
- **Numbers from a raw body:** `0.5`, `-1.25`, `-0.0`, `0.0000001`, `1E-6`, 10^20 and 10^21 as integer literals, and `2^53+1`.
- **Closed stdout:** inside the first row and inside the count line.
- **Table widths:** a long unknown form type, a TEAM value over the 15 cap, an ID over 36 columns, and NAME truncating at the 20-column floor.
- **U+4DC0:** padding and truncation; frozen `@std/cli` 1.0.28 measures it as one column.
- **Lowercase collation:** dotted capital I, Greek final and medial sigma, and a workspace/team tie.
- **Raw JSON the strict data fixture cannot express:** an object `templateData`, a non-JSON `templateData` string, a lone surrogate, missing `name` with null non-null fields, and extra unselected fields.

## Rust v3 obligations recorded here

Deno passes object-valued, non-JSON, null or missing fields, lone surrogates and extra fields straight through. Inspect each `c021-raw-*` case against the typed Cynic fragment: object-valued, null or missing required fields and lone surrogates may reject, while extra unselected fields will be omitted. The existing `Json(pub String)` scalar can retain a non-JSON string, so that case may match without a deviation. Bind named v3 goldens and compatibility entries only for observed differences. `c021-hexagram-width-text` needs a v3 width golden while Rust `unicode-width` measures U+4DC0 as 2. Every network case needs the reviewed `R01H-GRAPHQL-UA` golden, and the root-`--workspace` cases need the v3 grammar decision already required for C016.
